So funktioniert's

  1. Felder unten ausfüllen oder ändern (Texte, Zitate, Bücher, Presse, ...).
  2. Für kursiv in Buch-Absätzen: Text in *Sternchen* setzen — wird automatisch kursiv.
  3. Unten auf „Datei herunterladen" klicken — du bekommst content.json.
  4. Diese Datei auf GitHub hochladen und die alte content.json ersetzen (Datei anklicken → Stift-Symbol „Edit" oder „Upload file" → Commit).
  5. Die Seite lädt die neuen Inhalte automatisch beim nächsten Aufruf.
